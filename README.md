# 🌍 AI-Powered Disaster Management Application  

## 📖 Overview  
This project is an **AI-powered disaster management application** developed for **Smart India Hackathon 2024**. The application aims to provide:  
- Real-time disaster updates  
- Accurate weather forecasts  
- AI-powered tools to assist in disaster management  

The sleek and responsive user interface is built with **HTML**, **CSS**, and **Tailwind CSS**, ensuring an intuitive user experience. Multiple APIs are integrated to fetch real-time data and offer actionable insights for effective disaster response.

---

## ✨ Features  
- **📢 Live Disaster Updates:**  
  Fetches and displays real-time disaster data using APIs with a smooth scrolling effect.  

- **🌦️ Weather Forecasts:**  
  Provides comprehensive and real-time weather forecast details using:  
  - OpenWeatherMap API  
  - Two additional APIs for enhanced accuracy  

- **🤖 AI Assistance with Gemini API:**  
  Leverages AI-powered insights and responses for disaster management, powered by the **Gemini API**.  

- **🌀 IMD Forecast Integration:**  
  Combines weather data with **India Meteorological Department (IMD)** forecasts for improved decision-making.  

- **🌊 Tide Information:**  
  Features interactive tide charts, alerts, and predictions sourced from tidal APIs to assist in coastal disaster planning.  

---

## 🛠️ Technologies Used  

### Frontend  
- **HTML**  
- **CSS**  
- **Tailwind CSS**  

### Backend
